PDFnote プライバシーポリシー

最終更新: 2026年11月6日

1. このアプリについて

PDFnote は、個人の開発者が自分の学習用に作った、iPad・iPhone 向けの PDF 手書きノートアプリです。App Store などでは配布していません。開発者と、開発者が個別に許可した少数の利用者だけが使います。

2. 取得する情報

  • Google アカウントの情報: ログインのために、メールアドレスと表示名、プロフィール画像を受け取ります。
  • Google ドライブのファイル: ユーザーが選んだ PDF の取り込み、ノート(PDF と手書きデータ)の同期、バックアップのために、Google ドライブへのアクセス(スコープ https://www.googleapis.com/auth/drive)を使います。ユーザー自身の Google ドライブの中だけを対象にします。

3. 情報の使い道

取得した情報は、次の機能のためだけに使います。

  • ドライブにある PDF を、アプリに取り込む。
  • ノートと手書きを、ドライブの「PDFnote」フォルダに保存し、端末のあいだで同期する。
  • 端末のあいだで、設定や暗記カードをそろえる。

広告には使いません。販売も、第三者への提供も、開発者や他人が内容を読むことも、行いません。開発者が運営するサーバーはなく、情報は開発者のもとには送られません。

4. 情報の保管

  • ログインの情報(トークン)は、端末の Keychain に保存します。
  • ノートのデータは、ユーザーの端末と、ユーザー自身の Google ドライブにだけ保存します。

5. 外部のサービスについて

ユーザー自身が AI の機能を使ったときだけ、ユーザーが選んだ文章や画像が、ユーザー自身の API キーで、選んだ AI サービス(Anthropic、Google、OpenAI など)に送られます。ユーザーが操作しないかぎり、送られません。各サービスの扱いは、それぞれのプライバシーポリシーに従います。

6. Google API サービスのユーザーデータに関するポリシー

PDFnote による、Google API から受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(Limited Use の要件を含む)に従います。
PDFnote's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. 情報の削除

  • Google アカウントの「サードパーティによるアクセス」(https://myaccount.google.com/permissions)で、PDFnote のアクセスをいつでも取り消せます。
  • アプリを削除すると、端末の中のデータが消えます。ドライブのファイルは、ユーザー自身が削除できます。

English summary

PDFnote is a private iPad/iPhone note-taking app for annotating PDFs, used by its developer and a few invited people. It signs in with Google and uses the Google Drive scope to import the user's PDFs and to sync notes and handwriting into the user's own Drive. Data stays on the user's device and the user's own Drive. There is no developer server; the developer cannot see user data. Information is not sold, shared, or used for advertising. AI features send text or images selected by the user to the AI service chosen by the user, with the user's own API key, only when the user starts them. Use of Google user data follows the Google API Services User Data Policy, including Limited Use. Users can revoke access at https://myaccount.google.com/permissions. Contact: himmel756@gmail.com
